# 已确认需求基线

## 产品边界

- 面向公司内部 Windows 10/11 x64 已登录普通用户会话。
- 测试版最多登记 5 台设备；每台电脑使用独立、30 分钟、单次登记令牌。
- 测试授权默认 7 天且限定设备和管理员；本机停止后必须手动重新启用。
- 正式版每个新会话强制向本机用户显示管理员身份和权限并等待确认。
- 第一版只支持主屏幕低帧率远程查看、普通桌面输入和专用目录文件传输。
- 不提供系统服务、开机自启动、UAC/安全桌面绕过、任意命令执行和持续录屏。

## 固定限制

- 画面默认 1280×720、2 FPS、JPEG 质量 60、约 2Mbps、单帧最大 2MB。
- 欢迎图仅 PNG/JPG，最大 10MB、8192×8192。
- 文件默认上限 100MB，64KB 分块，临时文件完成后 SHA-256 校验并原子提交。
- 一个设备同时最多一个输入控制者。
- 服务端可看到中转内容；第一版没有端到端加密。

完整验收以用户批准的阶段开发计划为准；每个未实测条目必须在 `state.md` 标明，不能用模拟结果代替。
