# 架构概览

管理后台部署为 Render Static Site，通过 HTTPS 调用单实例 Node.js Web Service。Windows 客户端只主动建立 WSS 连接，不开放入站端口。服务端使用 Render PostgreSQL 18 保存身份、授权、会话和审计数据。

共享协议包定义版本、严格消息白名单和运行时校验。画面使用带固定二进制头的 JPEG 帧；输入和会话消息使用结构化 JSON。客户端、服务端和浏览器各自只保留一个待发送最新画面，出现背压时丢弃旧帧。

第一版限制服务端为单实例，因为活动 WebSocket 存在实例内存中。未来横向扩展必须增加连接目录和跨实例消息总线，不能直接增加实例数量。

测试版和正式版使用不同构建配置、Render 服务、数据库和密钥。正式确认策略编译进 Windows 客户端，服务端没有关闭确认的接口。
