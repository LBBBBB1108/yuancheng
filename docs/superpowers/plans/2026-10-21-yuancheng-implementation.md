# yuancheng 实施计划

> 状态：已获用户批准，按阶段执行；每个阶段必须形成可运行、可验证的成果。

## 阶段

1. 工程基础、依赖审计、文档、迁移与 CI。
2. 管理员认证、设备登记、在线状态和授权状态机。
3. 授权后的真实屏幕查看与背压控制。
4. 独占鼠标键盘控制与断线释放。
5. 受限文件传输和完整审计。
6. Render 测试/正式环境隔离、Windows 打包与实机验收。

## 全局约束

- Windows 客户端使用 C#、WPF、.NET 10 LTS，仅运行于普通用户桌面会话。
- 管理后台使用 React、TypeScript、Vite；服务端使用 Node.js 24 LTS、TypeScript、REST、WebSocket。
- 数据库使用 PostgreSQL 18，所有数据库变更通过版本化 SQL 迁移完成。
- 对外连接只使用 HTTPS/WSS；第一版服务端单实例，服务器可看到中转内容，不声称端到端加密。
- 测试版最多登记 5 台设备；正式版用户确认要求编译进客户端，不能由服务器关闭。
- 不实现系统服务、开机自启动、UAC 绕过、安全桌面控制、任意命令执行和持续录像。
- 所有用户界面和用户可见错误使用中文。
