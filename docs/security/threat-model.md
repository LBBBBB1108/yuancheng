# 安全边界

- 管理员密码使用 Argon2id；会话令牌和登记令牌在数据库中只保存 SHA-256 哈希。
- 管理员变更请求需要 HttpOnly 会话 Cookie 和独立 CSRF 令牌。
- 设备使用独立 Ed25519 密钥；私钥仅以 Windows DPAPI CurrentUser 范围保存。
- 第 6 台设备限制在 PostgreSQL advisory lock 保护的事务中检查。
- 管理员设备权限在服务端逐请求检查，前端隐藏按钮不是授权措施。
- JSON 消息拒绝未知类型、未知字段和协议版本；WebSocket 单消息硬上限 2MB。
- Render 外部通信必须使用 HTTPS/WSS，不允许跳过证书验证。
- 日志不记录密码、令牌原文、用户输入正文、文件内容或持续屏幕录像。
- 当前未完成：登录速率限制、设备挑战认证、会话凭证、正式确认、画面/输入/文件通道。
